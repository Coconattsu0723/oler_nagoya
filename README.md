# Oler（オレール）

名古屋市千種区のレストラン「Oler（オレール）」のWebサイトです。「調理を『引き算』で考える。」というお店のコンセプトを軸に、料理や店内の写真、アクセス情報を掲載しています。

[公開サイト](https://oler-website.web.app/)

## ページ構成

| ページ | 内容 |
| --- | --- |
| [トップページ](index.html) | お店のコンセプト、料理と店内の写真、アクセス、予約リンク |
| [料理ギャラリー](gallery.html) | 料理写真の一覧。写真を選ぶと拡大表示 |

## 実装

- HTML、CSS、JavaScriptで構成した静的サイト
- 画面幅に応じたレイアウトとハンバーガーメニュー
- 料理写真の拡大表示と店内写真の切り替え
- Firebase Hostingで公開

## ローカルでの確認

Python 3が使える環境で、リポジトリのルートから次のコマンドを実行します。

```sh
python3 -m http.server 8000
```

ブラウザで [http://localhost:8000/](http://localhost:8000/) を開きます。
